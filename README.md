
# 🎭🧠 AI Alter Ego Creator

An AI-powered application that helps users design a powerful **alter ego** with a clear identity, mindset, and behavior system to achieve personal growth and transformation.

---

## 💡 Overview

The AI Alter Ego Creator allows users to build a stronger version of themselves by generating:

- 🎭 A unique alter ego identity  
- 🧠 Mindset and personality traits  
- ⚡ Behavior rules and systems  
- 🎯 Daily actionable missions  

This tool bridges the gap between **who you are and who you want to become**.

---

## 🚀 Features

- 📝 Input-based persona creation (goal + weakness)
- 🎭 AI-generated alter ego identity
- 🧠 Personality traits and mindset rules
- ⚡ Behavior system for real-life application
- 🎯 Daily mission for actionable growth
- 📜 Save and review past personas
- ⚡ Interactive UI using Streamlit

---

## 🛠️ Tech Stack

- Python
- Streamlit
- Google Gemini API
- Session State (for storing personas)

---

## ⚙️ Setup Instructions

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/ai-alter-ego-creator.git
cd ai-alter-ego-creator
````

---

### 2️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

---

### 3️⃣ Setup Environment Variables

Create a `.env` file in the root directory:

```env
GOOGLE_API_KEY=your_gemini_api_key
```

Get your API key from:
[https://makersuite.google.com/app/apikey](https://makersuite.google.com/app/apikey)

---

### 4️⃣ Run the Application

```bash
streamlit run app.py
```

---

## 🧪 How It Works

1. Enter your **name (optional)**
2. Define:

   * 🎯 Your goal (e.g., “become confident”)
   * ⚠️ Your weakness (e.g., “overthinking”)
3. Click **Create Alter Ego**
4. AI generates:

   * Identity & persona
   * Behavior rules
   * Daily mission
5. Save and revisit your alter egos
